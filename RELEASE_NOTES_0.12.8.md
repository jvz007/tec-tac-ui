# Tec-Tac UI 0.12.8

## Troubleshooting & Diagnostics

- adds the Core Administration page at `/system/diagnostics`;
- presents problem-first PASS/WARNING/FAIL summary tiles and independently expandable diagnostic groups/checks;
- supports Run checks, explicit live capability health checks, Expand all/Collapse all, Copy summary and Download report;
- highlights installed module migration drift and links operators to the supported migration troubleshooting guidance;
- renders detailed diagnostic payloads in a compact technical surface without introducing module-specific styling;
- adds contextual Help articles for system diagnostics and migration drift;
- adds Troubleshooting & Diagnostics to Core Administration navigation and keeps backend authorization authoritative.
