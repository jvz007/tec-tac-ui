# Dashboards

Dashboards provide user-configurable operational views built from Core and module-provided widgets.

## Private and shared dashboards

A private dashboard is visible only to its owner. A shared dashboard is available to authenticated Tec-Tac users according to the current dashboard rules.

## Widgets

Installed modules can contribute widgets through the Core dashboard contract. The dashboard stores placement and size; the module remains responsible for the widget's data and behavior.

## Default and last dashboard

You can choose a default dashboard and optionally restore the last dashboard you used. These choices are saved with your Tec-Tac preferences.
