# Preferences and Menu Layout

Preferences are stored per authenticated Tec-Tac user.

## Appearance

Choose Dark, Light or High Contrast and select the text scale that is most comfortable for long operational sessions.

## Menu Layout

Menu Layout lets you reorder navigation categories and reorder pages inside each category. Category ownership remains authoritative: rearranging the menu does not turn an operational page into an Administration page.

Favorites remain a separate shortcut layer and can be managed from the navigation rail.
