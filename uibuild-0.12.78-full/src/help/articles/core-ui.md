# Tec-Tac interface

Tec-Tac uses one shared visual and interaction model across Core and installed modules.

## Common controls

- Blue **primary** buttons perform the preferred action in the current scope.
- Neutral buttons perform secondary actions such as Refresh or Close.
- Warning and danger treatments identify elevated-risk or destructive actions.
- Compact status pills show states such as enabled, queued, healthy or failed.

## Tables

Most operational collections use dense tables. Secondary IDs and technical values are normally shown in monospace beneath the human-readable value.

## Dialogs

Tec-Tac distinguishes between confirmations, input/action dialogs and read-only data-display dialogs. Important failures remain visible in the page or operation history instead of existing only as a toast.

## Themes

Dark, Light and High Contrast themes are available from the top bar. Text size can also be changed without changing page layout.
