# Tec-Tac UI 0.12.16

## Scheduler ownership split

- Split the operational Scheduler into User Schedules and Module Schedules.
- Added separate User History and Module History views.
- User schedules keep full create/edit/delete controls.
- Module schedules clearly show their owning module/key and remain read-only in the generic Scheduler UI.
- Run now remains available from both views subject to Core permissions.
- Updated help content and responsive Scheduler tabs.
