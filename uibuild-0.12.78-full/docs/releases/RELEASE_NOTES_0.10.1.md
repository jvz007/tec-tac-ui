# Tec-Tac UI 0.10.1

Navigation density release.

- Adds a persistent whole-rail collapse control.
- Collapsed rail keeps all currently visible core and extension destinations available as icon buttons with labels/tooltips.
- Adds independent collapse/expand controls for Workspace, Operations, Extensions, Administration, Configuration, and future navigation sections.
- Persists rail and section preferences in browser localStorage.
- Category collapse never changes module visibility or RBAC state; it is presentation only.
