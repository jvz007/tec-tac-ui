# Tec-Tac UI 0.9.0

## Developer Contracts workspace

- Adds **Administration → Public Contracts**.
- Displays the live Framework 1.10.0 developer contract catalog.
- Shows core Python framework contracts, registered cross-module capabilities, schedulable actions, extension permissions, and authenticated `/api/tfd/` HTTP routes.
- Adds contract search and live refresh.
- Adds **Export Markdown** and **Export Text**, backed by the framework's canonical live export endpoint rather than browser-only document generation.
- Requires Tec-Tac Framework `>=1.10.0,<2.0.0`.
