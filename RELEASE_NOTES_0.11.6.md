# Tec-Tac UI 0.11.6

## Per-user text size controls

- Added Small, Default, Large and Extra large text-size controls beside the existing theme selector in the top bar.
- Text size is stored in the existing server-backed user preference profile and follows the user across browsers/workstations.
- Added the same text-size setting to Preferences > Appearance.
- Existing Dark, Light and High contrast theme behavior is unchanged.
- Font scaling is applied through the shared Tec-Tac typography tokens/styles so Core and module UI text scale consistently without changing layout spacing.
