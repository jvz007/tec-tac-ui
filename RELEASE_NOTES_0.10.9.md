# Tec-Tac UI 0.10.9

- Adds stage-based lifecycle progress bars to Modules and System Updates.
- Keeps successful job output visible for five seconds before the automatic cache-refresh reload.
- Shows a visible reload countdown after successful module and system update jobs.
- Failed lifecycle jobs remain on-screen and do not auto-reload.
- Retains 0.10.8 context-action contracts and 0.10.7 cache invalidation behavior.
