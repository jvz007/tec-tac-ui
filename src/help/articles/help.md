# Help and Knowledge Base

The Tec-Tac Help system is owned by Core so every module uses the same experience.

## Context help

Click **?** in the top bar to see articles associated with the current page. Context help keeps you on the page while you read.

## Knowledge Base

Open the full Knowledge Base to search Core and installed-module articles by title, summary, keywords and article text.

## Module documentation

Modules may register versioned Markdown articles with Core. When a module is disabled or removed, its runtime Help contributions disappear with it.

## Deep links

Modules can open a specific article through the Core Help runtime instead of building private help dialogs.
