# Tec-Tac UI 0.11.3

- Adds Administration > Storage & Housekeeping.
- Shows managed `/var/lib/tec-tac` usage, purge candidates, item counts and protected areas.
- Retention can be configured per Core allow-listed category.
- Supports dry-run previews and explicit purge confirmation with reclaimed-space reporting.
- Requires Framework 1.15.7 or later.
