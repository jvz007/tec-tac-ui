# Tec-Tac UI 0.11.2

## Scheduler structured payload editor

- Replaces raw Targets/Parameters JSON textareas with a structured object editor.
- Supports nested objects, primitive lists, strings, numbers and booleans.
- Preserves an Advanced JSON mode for unusual payloads and troubleshooting.
- Target type is shown/selected separately from action-supported target types.

## Module lifecycle history

- Adds a History tab to Module Manager.
- Shows install/upgrade/remove/state/visibility jobs, requesting user where available, status/stage/timestamps, errors and persisted log tails.
- Reads the Framework 1.14.2 persistent history endpoint.
