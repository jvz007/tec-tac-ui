# Tec-Tac UI 0.7.0

## Module repositories and online catalog

- Adds Installed, Online catalog and Repositories views to Module Manager.
- Adds repository create/edit/remove, enable/disable, priority, trust and sync controls.
- Shows repository health, last sync state and indexed module count.
- Adds installed-vs-available module reporting with source, compatibility and update status.
- Online packages use Download & inspect and enter the existing package inspection/install workflow rather than installing immediately.
- Source-pinned modules are not silently switched to another configured repository.
