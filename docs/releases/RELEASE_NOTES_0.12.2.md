# Tec-Tac UI 0.12.2

## Scheduler full-width tables

- The Schedules workspace now uses the full available content width while the schedule editor is closed.
- Opening the editor switches the workspace to the intended table + 380px editor split.
- Run history continues to use the full page width.
- The schedule table wrapper is explicitly full width and its grid child may shrink correctly instead of reserving an empty editor column.

This is a UI-only corrective release; no Framework changes are required.
