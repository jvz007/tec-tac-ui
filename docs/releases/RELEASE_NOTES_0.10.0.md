# Tec-Tac UI 0.10.0

Scheduler hardening UI for Framework 1.11.0.

- Adds Scheduler Configuration & diagnostics.
- Adds configurable one-off retention control.
- Adds runtime tick/dispatch health and counts.
- Adds immediate, true scheduled, deliberate failure, and retry/recovery self-test controls.
- Expands execution history with action, run ID, Celery task ID and error type.
- Adds typed confirmation before Run now for dangerous actions.
- Updates delete messaging because scheduler history is now retained independently from schedule definitions.
