# Tec-Tac UI 0.8.0

Adds **Operations → Schedules** for Framework 1.8.0.

- Lists registered module actions and configured schedules.
- Creates and edits one-time, daily, weekly and monthly schedules.
- Stores IANA timezone per schedule.
- Exposes target/parameter payloads for module actions.
- Supports Run now, enabled state, retry, missed-run and concurrency policies.
- Shows durable execution history and failures.
