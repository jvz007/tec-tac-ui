# Tec-Tac UI 0.6.0

## Module visibility

- Adds Visible/Hidden state to the Modules catalog.
- Adds Hide/Show controls in Module Detail.
- Adds a Hidden summary count.
- Hidden modules remain loaded and routable; only top-level navigation registration is suppressed.
- `sync-modules.sh` now carries persistent visibility into `modules.json`.
- Existing modules default to visible.
- Requires Tec-Tac Framework 1.6.0 or newer.
