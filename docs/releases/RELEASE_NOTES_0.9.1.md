# Tec-Tac UI 0.9.1

Corrective release for Public Contracts export downloads.

## Fixed

- Export Markdown and Export Text now call the backend with `export_format=md|txt` instead of DRF-reserved `format=md|txt`.
- Prevents the 404 generated by Django REST Framework content negotiation before the export view runs.

Requires Tec-Tac Framework `>=1.10.1,<2.0.0`.
